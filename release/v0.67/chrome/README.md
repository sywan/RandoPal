# RandoPal V0.67 · Chrome extension package

V0.67 standardizes seat map terms: a horizontal row is 列 and a vertical column is 行. The builder labels, spacing options, help text, and newly generated seat map names now use the same convention. Seat assignments and saved maps remain compatible with V0.66.

Upload [RandoPal-chrome-v0.67.zip](RandoPal-chrome-v0.67.zip) to the **existing** RandoPal Chrome Web Store item. Its manifest version is `0.67.0`; the only permission is `storage`. The Store version remains unchanged until this package is reviewed and published. Existing Store installations then receive the update when Chrome checks for updates. An unpacked copy requires a manual reload.

The privacy policy remains at `https://sywan.github.io/RandoPal/privacy-policy.html`. The previous [V0.66 listing notes](../../v0.66/chrome/STORE-LISTING.md) still describe the seat export features.
