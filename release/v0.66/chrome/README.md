# RandoPal V0.66 · Chrome extension package

V0.66 adds exam spacing rules to Seat Shuffle and exports flat CSV, grid CSV, or a PNG seat map. The seat board uses available page height, and setup controls take less space.

Upload [RandoPal-chrome-v0.66.zip](RandoPal-chrome-v0.66.zip) to the **existing** RandoPal Chrome Web Store item. Its manifest version is `0.66.0` and its only permission is `storage`. The published Store version stays unchanged until this package is reviewed and published. Existing Store installations then receive the update when Chrome checks for updates. To check immediately, close extension pages, visit `chrome://extensions`, enable Developer mode, and click **Update**. An unpacked copy requires a manual reload.

The privacy policy remains at [privacy-policy.html](privacy-policy.html), publicly served at `https://sywan.github.io/RandoPal/privacy-policy.html`. Update the Store description and screenshots to show the V0.66 seat map options when submitting this package.
