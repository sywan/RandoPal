# RandoPal privacy policy · V0.55

The public privacy policy URL for the Chrome Web Store field is **https://randopal-privacy-policy.cguaacsb.chatgpt.site/**. It serves the Traditional Chinese / English policy, and an unauthenticated HTTP request returned 200. The editable copy is [`privacy-policy.html`](privacy-policy.html).

The current extension handles user-provided rosters, including names, student IDs, and any other imported fields, plus display choices, pick history, and preferences. It stores them with `chrome.storage.local` and does not transmit them to a RandoPal server or execute remotely hosted code. User-initiated presentation, clipboard copy, and CSV export can show or save selected results on the user's own device. Verify the hosted policy still matches the submitted package before publishing.
