# RandoPal V0.55 · Chrome extension

Use `RandoPal-chrome-v0.55.zip` for Chrome Web Store submission. The ZIP contains `manifest.json` at its root. `extension/` is the unpacked copy for local testing.

1. Run `npm test` and `npm run package` at the project root.
2. Open `chrome://extensions`, enable Developer mode, and choose **Load unpacked** with this directory's `extension/` folder.
3. Test the dance animation, language toggle, roster import, pick/order/group functions, and projection mode.
4. Upload the ZIP to the Chrome Web Store Developer Dashboard. Use [store copy and assets](STORE-LISTING.md) and the [privacy notes](PRIVACY.md).

The web app is separately available at [https://sywan.github.io/RandoPal/](https://sywan.github.io/RandoPal/). The previous Chrome package remains in `release/v0.50/chrome/`, and the original Guga animation remains in `backup/v0.50/`.
