# Microsoft Edge package

Test: open `edge://extensions`, enable Developer mode, choose **Load unpacked**, then select `extension/`. Use `RandoPal-edge-v0.50.zip` for Microsoft Partner Center, with `manifest.json` at ZIP root.

Publishing requires an Edge developer account in Partner Center. Create an extension, upload the ZIP, fill in listing, images, privacy, and availability, and submit for review. Use the same factual privacy draft in `../chrome/PRIVACY.md` and the screenshot in this directory.

The packaged App interface supports Traditional Chinese and English via the top-bar selector; the ZIP includes both extension metadata locales.

Official guide: https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension
