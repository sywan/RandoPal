RandoPal

隱私政策

更新日期：2026 年 11 月 3 日 · 適用於 RandoPal Chrome 擴充套件 V0.50

處理哪些資料

使用者可自行建立、貼上或匯入名單。名單可能包含姓名、學號及使用者自行加入的其他欄位；RandoPal 也保存選擇顯示的欄位、已抽選的紀錄及語言、音效等偏好。請只匯入完成活動所需的資料。

如何使用及儲存

擴充套件使用這些資料在裝置上執行隨機抽選、排序與分組，並顯示結果。資料透過 Chrome 的 storage.local 權限保存在使用者瀏覽器；使用者刪除名單、清除擴充套件資料或解除安裝後，相關本機資料會被移除。RandoPal 不會自動將名單、結果或使用紀錄傳送給開發者伺服器。

分享與匯出

RandoPal 不會將資料出售或提供給第三方，沒有廣告、分析或追蹤服務。使用者主動使用投影模式時，結果會顯示在自己的螢幕上；主動使用複製或匯出功能時，資料會寫入自己的剪貼簿或下載檔案。請在公開投影或分享匯出檔前確認顯示欄位。

權限與程式碼

storage 權限僅用於保存名單與偏好。本擴充套件不讀取瀏覽歷史或其他網站內容，也不執行遠端託管程式碼。

政策承諾

RandoPal 遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求；資料僅用於本擴充套件已揭露的隨機活動功能。

Privacy Policy

Updated November 3, 2026 · Applies to RandoPal Chrome extension V0.50

Data handled

Users may create, paste, or import rosters. A roster can include names, student IDs, and other fields supplied by the user. RandoPal also stores selected display fields, pick history, and preferences such as language and sound. Please import only data needed for your activity.

Use and storage

The extension uses this data on the device to pick names, set random orders, make groups, and show results. Data is saved in the user's browser through Chrome's storage.local permission. Users can remove it by deleting rosters, clearing extension data, or uninstalling the extension. RandoPal does not automatically send rosters, results, or usage records to a developer server.

Sharing and exports

RandoPal does not sell or share data with third parties and does not use ads, analytics, or tracking services. When a user chooses presentation mode, results appear on their own screen. When they choose copy or export, data is placed in their clipboard or a local download. Review selected display fields before presenting or sharing an exported file.

Permission and code

The storage permission is used only to keep rosters and preferences. The extension does not read browsing history or other websites and does not execute remotely hosted code.

Policy commitment

RandoPal adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only for the disclosed random activity features.
