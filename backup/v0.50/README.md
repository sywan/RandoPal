# Guga V0.50 animation backup

These are the original 1000 × 925 pixel animations saved before the V0.55 dance update:

- `guga-pal-hd.gif`: original 36-frame idle loop.
- `guga-pal-hd.webp`: WebP used in the V0.50 App.
- `guga-spin-hd.webp`: original pick celebration animation, retained in V0.55.

`build-guga-hd-v050.sh` is the old build script for reference. It is not part of the current build workflow.
